# Third-party notices

The Mega firmware declares OneWire, DallasTemperature, Bosch BSEC, Adafruit display libraries, ArduinoJson and Servo as external PlatformIO dependencies. BSEC includes vendor software/binary components with their own terms. Those downloaded libraries and build caches are not published as project-authored sources.

The ESP8266 uses its Arduino framework, ESP8266WebServer, ESP8266WiFi and LittleFS. Each external dependency retains its own license.

The supplied command-generator workbook is preserved as the project configuration artifact. The opaque CI1302 firmware binary is retained locally and withheld from the public repository pending confirmation of redistribution permission; its implementation source and redistribution terms were not supplied. No authorship over vendor internals is inferred here.

No repository-wide open-source license has been added.
